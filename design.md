# htwr-gobbler design system

An academic workbench, not a marketing page. Hallmark's Workbench, side-rail and inline footer are adapted for a working application; its landing-page screenshot framing is intentionally omitted.

Audience: RWTH students. Primary job: see what needs attention and whether its sources were actually checked. Tone: calm, practical, academic.

Garden-inspired paper and forest palette, Manrope headings and DM Sans body, roman headings. Named CSS tokens in apps/web/src/styles.css own every interface color. Quiet motion only, reduced motion honored. No stock photography or decorative product mockups. Thin dividers, asymmetric task/schedule columns, direct source links. Demo records always labeled; real workspaces start empty.

Desktop side navigation becomes a labeled menu on small screens. Native modal dialogs own focus and Escape handling. Verification badges must use words alongside colors. Body copy should remain readable on small screens. Source failures are explicit and never represented as an empty-success result.
